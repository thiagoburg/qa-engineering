# Automation QA

This stage begins after the Manual QA mastery checkpoint. It uses TypeScript and Playwright Test, selected for the target remote market and because Playwright appeared frequently in the current Argentina-eligible listing sample. This differs from the original master prompt's Python candidate because the user-approved planning direction selected TypeScript.

The learner-facing course teaches version control and only the TypeScript and test-runner concepts needed to maintain QA automation. Follow lessons 1–7 in [the roadmap](../ROADMAP.md). The Git/GitHub lesson comes before TypeScript so changes can be tracked as test code is introduced. No advanced programming curriculum is intended. Begin only after the Manual QA capstone review; passing the lesson assignments requires evidence, not just reading.
