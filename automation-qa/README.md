# Automation QA

This stage begins after the Manual QA mastery checkpoint. It will use TypeScript and Playwright Test, selected for the target remote market and because Playwright appeared frequently in the current Argentina-eligible listing sample.

The learner-facing course will teach only the TypeScript and test-runner concepts needed to maintain QA automation. Planned lessons are listed in [ROADMAP.md](../ROADMAP.md); no advanced programming curriculum is intended.
