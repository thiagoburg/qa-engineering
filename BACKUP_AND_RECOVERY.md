# Backup and Recovery

The public GitHub repository is the source backup for project files and committed learner submissions: <https://github.com/thiagoburg/qa-engineering>. It includes the curriculum, application source, migrations, templates, [master prompt](MASTER_PROMPT.md), context handoff, and Obsidian vault settings. The project is designed so generated dependencies and local app state can be recreated.

## Restore the project

In PowerShell, clone the repository and install the app dependencies:

```powershell
git clone https://github.com/thiagoburg/qa-engineering.git
Set-Location qa-engineering/taskflow-qa-lab
npm ci
npm run db:migrate:local
npm run dev
```

The local app opens at `http://localhost:8787`. `wrangler.jsonc` contains the Supabase project URL and publishable key needed for the training app. These are public configuration values. Optional local overrides belong in `.dev.vars`, which is ignored by Git; do not add secrets, service-role keys, or real credentials to the repository.

Start the learning path at [Manual QA 1](manual-qa/01-thinking-like-a-qa-engineer.md). Learner submissions should be saved under `submissions/` and committed when they are ready to back up. No learner mastery checkpoint is complete until the work is reviewed and `PROGRESS.md` is updated with evidence.

## Recover the training branch

The stable course and app are on `main`. The separate `training/taskflow-release-01` branch is reserved for the Manual QA capstone. Fetch it only when the lesson calls for it:

```powershell
git fetch origin
git switch --track origin/training/taskflow-release-01
```

Use a fresh **local** D1 database for that exercise. The reset command is `npm run db:reset:local` from `taskflow-qa-lab/` and targets local D1 only. Do not merge the training branch into `main` or deploy it to production. Return to the stable branch with `git switch main` after the exercise.

## What is intentionally not in GitHub

GitHub stores the project source, not sign-in sessions, third-party account access, or local databases. Recreate or reauthorize these if needed:

- `node_modules/` is recreated with `npm ci` from `package-lock.json`.
- `.wrangler/` contains local tool/development state and is regenerated by Wrangler.
- `.dev.vars` is a local override file and is ignored; the tracked Wrangler config already contains public Supabase URL/key settings.
- Obsidian's per-device graph/workspace state and `.trash/` are local UI history, not course content; the core vault settings remain tracked.
- Wrangler, Cloudflare, GitHub, and Supabase login sessions and account/database passwords are not stored in this repository. Sign in to those services again when needed; never put passwords or private tokens in Git.
- Local D1 training data is not a backup. Use invented practice data only and recreate it with migrations.

This repository is public. Before committing learner submissions, remove personal information, real credentials, access tokens, private employer material, and any data that should not be public.
