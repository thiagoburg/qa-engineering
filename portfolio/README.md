# Portfolio Guide

Use the repository to show practical QA work, not just course completion.

## What to feature

- A concise README that explains the product and how to run its checks.
- A few carefully selected test designs, execution summaries, and reproducible bug reports.
- An automation suite with clear setup instructions and useful failure evidence.
- A short explanation of risks tested, tradeoffs, and what remains untested.
- An honest contribution record using [PROVENANCE.md](PROVENANCE.md) and [CONTRIBUTION_LOG.md](CONTRIBUTION_LOG.md).

## Before sharing

- Remove secrets, real personal information, and confidential data.
- Verify links and commands from a clean checkout.
- Make sure you can explain every artifact you present.
- Label AI-assisted work and distinguish it from learner submissions.
- Avoid claiming that a completed roadmap guarantees employment.
