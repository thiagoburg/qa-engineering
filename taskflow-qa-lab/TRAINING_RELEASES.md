# Training Releases

The current `main` release is the stable baseline and contains no intentionally introduced defects.

Controlled defective releases will be added as separate, explicitly named training versions for bug-hunting exercises. Each exercise will identify the build to use and provide only the behavior requirements needed for testing. The defect details stay out of the learner-facing assignment until the submission has been reviewed.

No training defects are included yet. They will be added when the Manual QA capstone is prepared, with a matching fix and regression check so the stable baseline remains reliable.
