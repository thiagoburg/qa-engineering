# Job Preparation 2: English CV and LinkedIn

## Introduction

This lesson turns verified QA evidence into a concise English CV and a consistent LinkedIn profile. It does not invent professional experience.

## Learning objectives

- Organize a junior QA CV around evidence and relevant skills.
- Write clear project bullets using action, scope, tools, and outcome.
- Make a LinkedIn profile consistent with the CV.
- Protect contact and identity details in public drafts.

## Concise theoretical explanation

A CV is a short, role-focused summary, not a course transcript. Use sections for contact/location and work eligibility as appropriate, profile, skills, projects, experience (if any), education, and languages. State your actual English level honestly. Put the strongest evidence early and tailor wording to a job's requirements without copying claims you cannot support.

A project bullet can use: **action + scope + method/tool + evidence/result**. Example template: “Designed and executed [number] checks for [feature/risk] using [method]; documented [result] with reproducible steps and [evidence].” Replace brackets only with verified facts. Distinguish practice projects from paid work. LinkedIn headline and About section should match the CV and link to the portfolio. Argentina-based candidates should state location/time-zone overlap clearly when useful; do not imply work authorization you do not have.

## Practical examples

Avoid “Expert in Playwright” after one exercise. Prefer “Built a practice suite with Playwright Test covering [verified scope]; reviewed CI failures using traces.” Be prepared to demonstrate each statement.

## Guided practice

1. Gather only verified facts: tools used, reviewed artifacts, test counts/results, languages, location/time zone, and any experience.
2. Draft a one-page CV in English. Include 2–3 project bullets with placeholders where evidence is not yet available.
3. Replace each placeholder only after review/execution; remove unearned skills and generic claims.
4. Draft a LinkedIn headline and About paragraph consistent with the CV.
5. Read both aloud for clarity, correct grammar, and check links/contact visibility settings.

## Assignment

**Tools:** word processor or Markdown; CV template below. **Deliverable:** `submissions/job-preparation/cv-draft.md` and `linkedin-draft.md`. Use placeholders such as `[add after capstone review]` for missing personal details; do not invent an address, experience, credential, or performance result. **Submission location:** `submissions/job-preparation/`; keep drafts private until personally reviewed.

Suggested CV outline:

```text
Name | Argentina (UTC−3) | email | portfolio URL
QA profile (2–3 evidence-based lines)
QA skills (only skills you can demonstrate)
Selected QA projects (problem, action, evidence, result)
Experience (if applicable; otherwise omit)
Education | Languages | Work eligibility (only if relevant and accurate)
```

## Definition of Done

- CV is concise, readable, and in English.
- Project work is labeled as practice and matches portfolio provenance.
- Every skill and outcome is defensible with an example.
- LinkedIn draft is consistent; private details are not accidentally public.

## Submission instructions
